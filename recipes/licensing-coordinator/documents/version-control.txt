The unit of correction is the application drawing, not the number of departments that spotted the discrepancy.

Public method: before reading a register, check that the coordinator may work on the specific application, consult both named desks and prepare a correction. If any element is missing, give the general access requirement without confirming an application. A conflict in file labels does not identify the correct drawing; the highest number and latest arrival are not verification.

If two legible desk copies disagree, check for an existing correction thread. Where there is none, prepare one request identifying the conflicting references, the drawing feature in dispute and what the applicant should return. On an open thread, retain the references and await a signed replacement; do not ask each desk to contact the applicant. The custodian checks application match, sheet identity and the signed revision before releasing its pointer for coordination.

Compare that verified pointer with each desk's register separately. Propose it only for the desks that still differ. Ask for acknowledgement, preserve the superseded references and let each desk continue its own review. Reconciliation neither settles the merits nor grants a licence.
